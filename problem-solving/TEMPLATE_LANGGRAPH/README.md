## 2. 왜 LangGraph인가

`framework-selection` 판단 결과를 적는다. 레이어를 잘못 고르면 나머지가 다 틀어진다.

| 질문 | 답 | 근거 |
| :--- | :--- | :--- |
| 계획 수립·파일 관리·세션 간 메모리가 필요한가? | | → 예면 Deep Agents |
| 루프/분기/병렬/HITL/커스텀 상태가 필요한가? | | → 예면 **LangGraph** |
| 고정 툴셋의 단일 목적 에이전트인가? | | → 예면 LangChain `create_agent` |
