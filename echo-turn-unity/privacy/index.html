개인정보처리방침

시행일: 2026년 10월 24일

상상공방(Google Play 개발자명: jeo)은 또각 공방 앱과 이 정책 웹사이트에서 정보를 어떻게 다루는지 안내합니다.

한눈에 보기

  • 플레이 기록과 환경설정은 기기의 앱 저장공간에 보관하며, 개발자 서버로 업로드하는 기능은 없습니다.
  • 이용자가 직접 보낸 이메일의 발신자 정보와 문의 내용은 지원을 위해 처리합니다.
  • 기기 백업과 정책 웹사이트의 접속 기록에는 각 서비스 제공자의 정책과 이용자 설정도 적용됩니다.

1. 기기에 저장하는 플레이 정보

진행도, 최고 기록(PB), 공명 인장, 현재 플레이 상태, 음소거 및 모션 줄이기 설정은 Unity의 기기 내 저장 기능인 PlayerPrefs를 사용해 앱 저장공간에 보관합니다. 이 정보는 진행을 이어가고 기록과 환경설정을 유지하는 데 사용합니다.

앱에는 로그인이나 계정 생성 기능이 없습니다. 개발자는 플레이 기록을 받아 보관하는 별도 서버를 운영하지 않으며, 앱에는 이 기록을 개발자에게 전송하거나 업로드하는 기능이 없습니다.

2. 저장 정보 삭제와 백업 관리

기기의 앱 데이터가 유지되는 동안 플레이 기록과 설정도 남아 있습니다. Android에서는 기기 설정의 앱 목록에서 또각 공방을 선택한 뒤 저장공간의 데이터 삭제 기능으로 앱의 로컬 데이터를 지울 수 있습니다. 메뉴 이름과 경로는 기기와 운영체제 버전에 따라 다를 수 있으며, 삭제한 로컬 기록과 설정은 앱에서 다시 사용할 수 없습니다.

Android 또는 Google의 백업·복원 기능은 기기와 계정의 설정에 따라 앱 데이터를 백업하거나 복원할 수 있습니다. 기기 및 Google 계정의 백업 설정에서 백업 사용 여부와 보관된 백업을 확인·관리해 주세요. 앱 삭제나 로컬 데이터 삭제가 기존 클라우드 백업까지 영구 삭제한다는 뜻은 아닙니다.

개발자는 이용자 기기의 저장 정보나 운영체제·계정 백업을 원격으로 열람하거나 삭제할 수 없습니다. 관리 방법에 관한 문의는 아래 연락처로 보낼 수 있습니다.

3. 이용자가 직접 보내는 문의 이메일

이용자가 지원 또는 개인정보 문의 이메일을 보내면 발신자 이름·이메일 주소, 메시지 내용과 직접 첨부한 자료가 전달될 수 있습니다. 이 정보는 문의 확인, 답변 및 해당 문제의 지원을 위해 사용합니다. 이메일 전송 여부와 포함할 내용은 이용자가 선택하며, 비밀번호나 불필요한 민감정보는 보내지 말아 주세요.

문의 정보는 지원과 필요한 후속 확인을 위해 보관하며, 그 목적을 위해 더 이상 필요하지 않으면 삭제합니다. 이메일의 전송·보관에는 이용자의 메일 제공자와 개발자가 사용하는 Gmail의 처리가 수반됩니다. 해당 제공자의 정책도 적용되며, Google의 처리에 관한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.

4. Unity와 외부 서비스

또각 공방은 Unity 엔진으로 제작되었습니다. 선택형 Unity 온라인 서비스의 사용 설정은 꺼져 있으며, 별도의 분석·광고 SDK는 연동하지 않았습니다. 개발자가 만든 네트워크 API를 통해 플레이 정보를 수집하는 기능도 없습니다.

선택형 서비스의 비활성화가 Unity 엔진이나 운영체제, 앱 스토어의 모든 데이터 처리가 없다는 뜻은 아닙니다. 각 제공자가 수행하는 처리에는 해당 정책과 이용자 설정이 적용됩니다. Unity의 데이터 처리 안내는 Unity 개인정보처리방침에서 확인할 수 있습니다.

5. 정책 웹사이트 접속

앱의 개인정보처리방침 버튼을 누르면 외부 브라우저에서 이 페이지를 엽니다. 이 웹사이트는 GitHub Pages에서 제공하며, 호스팅 제공자인 GitHub가 IP 주소, 접속 시각, 요청한 페이지, 브라우저 정보 등 일반적인 웹 접속 기록을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.

개발자는 이 페이지에 분석 도구, 추적 코드, 쿠키를 추가하지 않았습니다. 페이지에는 스크립트나 입력 양식이 없으며, 외부 글꼴·이미지를 불러오지 않습니다. 외부 정책 링크를 선택하거나 이메일을 보내면 해당 웹사이트 또는 메일 서비스의 데이터 처리 정책이 적용됩니다.
